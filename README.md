# 会话用量（Session Insight）

> 实时查看每个会话的 Token 消耗、缓存命中率、费用与余额，加上多供应商账户状态、逐轮趋势与全局用量分析。

HanaAgent 的会话用量面板。完整工作台常驻左侧导航，点开就是当前会话的 Token、缓存命中率、费用与余额、逐轮趋势图表，以及各供应商账户的真实余额、配额与官方成本。数据全部来自宿主公开接口，管理凭据只留在后端。

## 功能

- **会话级用量指标**：总 Token、缓存命中率、会话费用、轮数、运行时长
- **图表分析**：每轮 Token、缓存命中率趋势、每轮费用、输入构成（未命中 / 缓存 / 输出），支持悬停读数和点击放大
- **输入栏本轮速览**：缓存命中率、速度、用量、费用、耗时五项
- **上下文构成**：逐项列出当前上下文里已经用掉的部分
- **多供应商账户状态**：DeepSeek / Moonshot 真实余额、智谱 Coding Plan 配额、OpenAI 官方累计成本、xAI API 预付余额，以及可选的 Codex 订阅配额
- **混用模型会话识别**：统计会话内的模型分布与主模型归属，费用按每轮实际模型价格累计
- **跟随当前会话**：工作台和实时用量跟随主窗口选中的会话，也能手动锁定到任意一个查看
- **双形态**：整页工作台，加上可以放到画布上的实时用量卡片
- **主题同步**：跟随 HanaAgent 当前主题，深浅色自适应
- **来源可查**：每个会话都能看到用过哪些供应商、哪些模型，价格来自哪里
- **本地供应商一键启动**：Ollama / FreeToken
- **自定义计费**：设置页集中管理供应商与模型价格，资费列表可直接补录；本地规则优先参与实际费用计算，支持 CNY / USD、缓存写入、启停与删除恢复公共价
- **价格投稿**：预览后打开预填 GitHub Issue，由用户确认公开提交；不上传凭据、余额或会话数据
- **检查更新**：有新版直接列出更新日志

## 用法

- **工作台**：左侧导航「会话用量·工作台」。首页可以设成用量页或 API 管理页
- **实时用量卡**：从卡片中心拖到画布，随当前会话刷新
- **输入栏速览**：会话输入框下方一条状态

## 安装

1. 从 [Releases](https://github.com/youyongdemao/HanaAgent-session-insight/releases) 下载 `session-insight-v*.zip`
2. 在 HanaAgent「设置 → 扩展」中安装
3. 安装时逐项确认下面这些能力

| 能力 | 用途 |
|------|------|
| `app/tools.expose-to-model` | 向模型暴露一个读数据的工具 |
| `app/sessions.read` | 读取会话列表与上下文（跟随当前会话需要） |
| `app/usage.read` | 读取宿主用量账本 |
| `app/provider.credentials.read` | 读取供应商凭据以查询余额 |
| `app/resources.read`、`app/models.read` | 读取资源与模型目录 |
| `app/input.status` | 会话输入栏的状态位 |
| `app/process.spawn` | 拉起本地供应商进程（一键启动用） |

## 设置

| 配置项 | 说明 | 默认 |
|-------|------|------|
| `liveLayout` | 输入栏「本轮速览」显示哪几项 | 五项全开 |
| `widgetLayout` | 「实时用量」卡片显示哪几个区块 | 全部显示 |

另有一组高级视觉效果开关：毛玻璃和鼠标跟随光晕。

## 计费数据库

价格不写死在代码里。仓库根目录的 `pricing.json` 是唯一事实源，包含单价、高峰时段、模型归属供应商、上下文窗口和来源标注。

- **拉取**：App 启动后按 24 小时 TTL 拉一次，先走 jsDelivr CDN，失败回退 GitHub raw，两者都不可用就用随包的内置快照
- **校验**：逐字段校验，非法值（负数、缺字段、类型错误）整条丢弃；整份配置都无效时保持内置数据不变
- **维护价格**：改仓库里的 `pricing.json` 并推送，客户端最迟 24 小时后生效

公共价格取自各供应商官方定价页，查不到的模型标「未收录」，不借用其他供应商的同名模型价格。

### 订阅套餐

设置页「订阅套餐」提供独立的本地账本。目前自动查询适配火山方舟个人 Coding Plan，复用供应商设置中的管理端 AccessKey ID / SecretAccessKey，使用 `ListSubscribeTrade` 只读接口；需要相应 IAM 读取权限。模型推理 API Key 不能代替管理凭据。新增网络权限仅声明 `open.volcengineapi.com`，安装时由宿主审核，不使用子进程绕过网络授权。

官方结束时间自动同步；尚未核实的生效时间、实付金额不猜测，需按实际账单补录。三项齐全后，按实际有效期经过的比例分摊人民币成本，进入总消耗、今日成本和费用曲线；实付金额单独展示，不再叠加一次。美元记录保存入账汇率，不因之后公共汇率改变而漂移。套餐账本不会分摊回逐轮会话，套内模型的计费类型应为「订阅」，避免与按量费用重复。

新结束时间会创建一个新的待补录周期，不推测续费金额；同一官方订阅的重叠完整计费周期会阻止保存，避免重复累计。删除的官方条目不会被下次同步复活。权限不足或查询失败保留上次已确认记录，不影响原有额度查询。团队版和其他供应商尚未自动适配，可以对已标识为订阅的供应商手动登记。

`subscriptions.json` 独立保存在 App 私有数据目录，采用串行原子写入与修订号冲突保护；付款信息不进入公共价格 Issue 投稿，也不写入浏览器存储。自动同步约十五分钟一次，管理页可手动发起只读同步。

### 自定义计费

在「设置 → 自定义计费」管理本地条目，也可以在资费表中点「补充价格 / 自定义价格 / 编辑」。条目精确绑定 Hana 回报的供应商 ID 与模型 ID，不修改宿主的模型连接或 API Key。固定单价以人民币或美元 / 百万 Token 填写，美元跟随公共库汇率折算；缓存写入留空时沿用未命中输入价，明确的 0 表示免费。

本地覆盖独立保存在 App 数据目录的 `custom-pricing.json`，重启或公共库更新不会覆盖。保存后参与逐轮、会话和用量账本的费用计算；停用或删除后恢复公共价格，公共库也没有则保留未知。价格改变不会改动真实 Token、供应商余额或官方账单。仍有明细的会话可按当前价格重新估算；已经冻结且缺少原始明细的小时/日汇总保留原金额，不承诺完整历史回算。

投稿需提供来源，在预览中确认公开内容后再打开 GitHub 页面，最终提交由用户在 GitHub 完成。仅导出计费白名单字段，来源链接剥离查询参数与片段，私网链接不公开；备注和模型标识仍请用户自行检查。投稿不会自动写入公共库。

## 已知限制

- 账户数据分四种口径：真实余额、官方累计成本、订阅配额、暂不可查询。管理凭据只在后端读取，不会发送到面板页面
- 订阅与免费类通道不按 token 计费，这类会话只做展示，不计入费用
